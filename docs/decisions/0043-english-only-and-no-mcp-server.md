# 0043: English only, and no MCP server

**Who decided:** Ionel for English only; Claude for no MCP server. 2026-11-05.

**Decision.**
- Languages other than English are a non-goal.
- There is no MCP server.

**Why.** The brief makes the MCP server optional, and four days don't fit it. The spec gives no reason for English only.

**Rejected.**
- Building the MCP server.
- Supporting other languages.

**Cost.** The README lists the MCP server as a departure from the brief.

**Source:** [the spec](../superpowers/specs/2026-11-05-aeca-design.md), §2 and §12.
