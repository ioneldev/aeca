# 0045: No questions are sent to the evaluators

**Who decided:** Ionel. 2026-11-05.

**Decision.**
- AECA needs no answers from the evaluators, so no questions are sent.
- Each point in their setup works whatever they do, or is a setting they choose. The README's "Before you start" section states them.

**Why.** AECA works whichever mailbox, internal list, approver, OS and calendar they use. The one thing it can't run without is the Anthropic key, which Ionel arranges (see 0042).

**Rejected.**
- Sending a questionnaire first (inferred).

**Cost.** The README must state every setting the evaluators may change.

**Source:** [the spec](../superpowers/specs/2026-11-05-aeca-design.md), §6 and §10.
